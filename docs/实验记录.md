# 实验记录

> 本文件只记录**能从仓库内产物核验**的实验结果；数字与 README、`results/` 一致。
> 旧版（2026-11-16 自动生成）里的 98.61% / 15.93 ms / 396.8 张/s / 23.59 M 等口径
> 与 README、`results/benchmark.json` 冲突且无法从仓库复算，已整段重写。

## 一、数据与划分

| 项目 | 数值 | 是否随仓库提供 |
|---|---|---|
| PlantVillage 原始数据 | 54,381 张 / 38 类 / 14 作物 | 否 |
| 完整配平划分（70/10/20） | 训练 5,286 / 验证 755 / 测试 1,511 | 否 |
| 本仓库 `data/splits.json` | 8 类冒烟子集：训练 224 / 验证 32 / 测试 64 | 是 |

冒烟子集来自 `scripts/make_smoke_subset.py` + `scripts/prepare_data.py`，用于验证链路，
不能与完整数据集上的指标并列比较（详见 README「最小复现」）。

## 二、同分布准确率的三个分母

三个值来自三套不同的评测集，不能互相替换：

| 数字 | 分数 | 评测集 | 出处 |
|---|---|---|---|
| 95.67% | 265/277 | 生成 `results/cross_domain_resnet50.json` 那次评估所用 `splits.json` 的 test 划分（277 张）；该划分与原始 `eval_resnet50.json` 未随仓库提供 | `results/cross_domain_resnet50.json` 的 `in_domain_accuracy`（0.9566787） |
| 98.52% | 1064/1080 | 同分布 test 中能映射到 PlantDoc 27 类的子集，只用于和域 B 对照 | `results/cross_domain_diag.json` 的 `acc_A_subset`（`n_A=1080`） |
| 98.61% | 1490/1511 | 完整配平划分的 test（1,511 张），未随仓库提供 | 旧版本文档口径，无法从仓库复算，仅作分母对照 |

README 以 95.67% 为主口径。

## 三、跨域泛化（PlantDoc，n=236）

| 设置 | 数值 | 出处 |
|---|---|---|
| 严格协议（38 类直接 argmax） | 12.29%（29/236） | `results/cross_domain_diag.json` 的 `acc_strict` |
| 折叠协议（映射到 27 类后 argmax） | 38.98%（92/236），Wilson 95% CI [33.0, 45.3] | 同上 `acc_fold`、`ci_low`/`ci_high` |
| Top-3 / Top-5 | 58.90% / 66.95% | 同上 |
| 多数类基线 | 5.08% | 同上 `majority_baseline` |
| 域判别器（5 折 CV） | 94.81% | `results/domain_classifier.json` |
| 一致性分层 | 一致组 65%（n=80）/ 不一致组 25.64%（n=156） | `results/cross_domain_diag.json` 的 `consistency` |

`acc_restrict` 与 `acc_fold` 完全相等（236 个样本上 1:1 映射等价），因此不把受限协议
单列成一个「更好的结果」，见 `results/cross_domain_protocol.json`。

## 四、最小复现（链路冒烟）

出处 `results/smoke_minimal.json`：8 类 × 40 张 = 320 张，ResNet50 训练 3 轮
（loss 3.3411→2.2120，val_acc 78.1%），test 64 张 top-1 84.38%，4 张示例图 top-1 全对，
预热后单张 11.2 ms。这是链路验证，不是完整数据集指标。

## 五、推理性能

`results/benchmark.json` 是 **旧的 127 类模型**产物：参数量 23.77 M / 4.17 M / 4.36 M，
分类头比当前 38 类模型多 182,361 / 114,009 / 114,009 个参数。它记录的
ResNet50 9.16 ms、109.2 张/s 只能作为同代骨干在 RTX 4060 上的量级参考，
**不能当作当前 38 类流水线的性能口径**。当前 38 类冒烟模型实测 11.2 ms/张。
