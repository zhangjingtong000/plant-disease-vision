## 第 6 层：人工复审（四透镜）

### 发现并修复的 3 个真实缺陷

**① 切换 backbone 崩溃（严重）**

现象：`resnet50_best.pth` 换成 127 类后，切到 EfficientNet/MobileNet 直接
`RuntimeError: Error(s) in loading state_dict for EfficientNet`。

根因：另外两个 backbone 的权重仍是 38 类，分类头尺寸不匹配。

修复：`get_model` 加载失败时降级到主模型（`app/web.py`），并重训两个 backbone 到 127 类。

**② `clear_history` 不存在（功能缺失）**

现象：历史页没有「清空全部」入口，后端也没有对应函数。

修复：新增 `clear_history(backup=True)` 与 `restore_history()`，清空前自动备份 `.bak`。

**③ 评估页文案残留旧模型标注**

现象：3 处硬编码「38 类旧模型」「训练中，完成后替换」。

修复：改为动态 `{_NCLS}`。


**④ 全屏查看无法关闭（用户反馈）**

现象：图片点开放大后，点击其他区域无法关闭，只能按 ESC。

根因：全屏时 `img` 被拉伸到 1440×900 铺满整屏，用户以为点在"空白处"，
实际点的是图片自身的白底（训练曲线图有大量白边），因此点击不触发关闭。

修复：
- CSS 把全屏图片限制为 `92vw × 92vh` 并居中，周围留出半透明遮罩
- 注入 JS（`launch(head=)`）：点击图片外侧空白关闭、按 ESC 关闭
- 全屏时显示提示条「点击图片外侧空白处或按 ESC 关闭」，退出后自动移除

验证：Playwright 实测 打开→点空白→关闭、打开→ESC→关闭，提示条出现与移除均正常。
